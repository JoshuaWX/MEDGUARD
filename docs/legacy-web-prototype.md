# Legacy web prototype

MedGuard was originally explored through static HTML/Vite screens and an experimental Node/Python chatbot. Those artifacts are not the supported product path and were removed from the public repository during the Release-4 cleanup. A private recovery bundle is retained by the project owner.

The maintained application is `mobile-expo/`, with server-side logic and schema under `supabase/` and the weekly forecast pipeline under `ml/`.
