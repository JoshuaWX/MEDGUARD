# Fonts Directory

Place the following Inter font files here:

- `Inter-Regular.ttf` (400 weight)
- `Inter-Medium.ttf` (500 weight)
- `Inter-SemiBold.ttf` (600 weight)
- `Inter-Bold.ttf` (700 weight)

## Download

You can download the Inter font from:
- Google Fonts: https://fonts.google.com/specimen/Inter
- Inter Font Website: https://rsms.me/inter/

## Instructions

1. Go to https://fonts.google.com/specimen/Inter
2. Click "Download family"
3. Extract the ZIP file
4. Copy the following files from the `static` folder:
   - Inter-Regular.ttf
   - Inter-Medium.ttf
   - Inter-SemiBold.ttf
   - Inter-Bold.ttf
5. Paste them into this directory
